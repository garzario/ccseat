# ccseat documentation

ccseat lets you use all your Claude Code accounts side by side. Each account is a **seat**: its own login and usage limits, with one shared setup. New here? Start with the [quick start](../README.md#quick-start) in the README.

## Using ccseat

| Page | Read it to |
|---|---|
| [Installation](installation.md) | install with one line, Homebrew, a clone or `make`; set up the shell; update; uninstall |
| [Usage](usage.md) | add accounts, use `claude`, pick a seat with `cc`, read the usage with `ccseat list`, see what LIMIT REACHED means, and set up the status line |
| [Commands](commands.md) | look up any command and its options |
| [Configuration](configuration.md) | change a setting, share less, and see which files ccseat keeps |
| [FAQ](faq.md) | find quick answers: is it allowed, is it safe, Linux, isolation, editors |
| [Troubleshooting](troubleshooting.md) | fix a setup with `ccseat doctor` and the common problems |
